# Stage gates and scientific interpretation

| Stage | Input | Output | Required decision |
| --- | --- | --- | --- |
| Phase 0 | Frozen study protocol | Definitions/hypotheses | Proposed, audit-dependent |
| Phase 1A.0 | Original preflight package | Verified documentation and source catalog | Integrity pass, raw gate blocked |
| Phase 1A.1 | Official raw tables, KLASS and metadata | Source hashes and receipts | Completeness and provenance review |
| Phase 1A.2 | Audited source variables | Exact code/unit mappings and coverage | Accounting and definition review |
| Phase 1A.3 | Raw identities and financial measures | Harmonized eligibility panel | All blocking quality gates pass |
| Phase 1B | Validated eligibility + baseline covariates | Matched strong/weak pair | Selection rules frozen |
| Phases 2–5 | Matched cases + financial statements | Ten-year results and comparison | Findings with limitations |
| Phase 6 | Wider municipality panel | Nationwide inferential/predictive tests | No causal overreach |
| Phase 7 | Results and audits | Paper, evidence tables, reproducibility | Full traceability |
