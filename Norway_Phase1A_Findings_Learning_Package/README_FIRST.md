# Phase 1A Findings Learning Package

This is a **snapshot and explanatory supplement**, not an overwrite of existing
GitHub research logs or an approved numerical analysis dataset.

## Files
- `docs/PHASE1A_FINDINGS_LEARNING_GUIDE.md`: Full explanations, formulas, evidence limits and next steps.
- `research/records/phase1a_findings_table.md`: Human-readable snapshot ready for GitHub.
- `research/records/phase1a_findings_matrix.csv`: Auditable findings with statuses and evidence locators.
- `research/records/phase1a_problem_fix_log.csv`: What failed, why, how it was fixed, and remaining risks.
- `PHASE1A_Findings_and_Progress.xlsx`: Spreadsheet tabs for overview, findings, indicator audit, problems, roadmap.

## Source-status statement
The findings use the user's posted terminal logs and public GitHub script
contents. Original SSB raw data and local definition-review CSV were not supplied
to the assistant for direct independent inspection. No 10-year empirical
outcomes or case rankings are claimed.

## GitHub destinations
Copy the `docs/` and `research/records/` files into those same relative folders
in the VS Code repo. Copy the `.xlsx` into `research/records/` only if desired.
